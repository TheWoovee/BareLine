# PR005 native folder-search controls — source handoff

The FINAL checkout now opens a docked Find in Folder configuration panel after native folder selection. The panel edits the pattern and comma-separated extension/excluded-directory filters, and exposes explicit Include binary / NUL-heavy files and Continue counting beyond retained result limit choices. Search constructs the existing FolderScope and SearchQuery and submits them through SearchPanel::start_folder; cancellation leaves the current document and search job unchanged. Retried searches inherit the submitted scope/query through the existing SearchPanel contract.

Defaults remain binary exclusion, no count beyond retained results, all extensions, and .git/.svn/.hg directory exclusions. Filters accept exact extensions plus the familiar *.rs spelling; unsupported path/glob expressions fail visibly instead of being misinterpreted. Filter inputs are capped at 4096 bytes, 64 entries, 128 bytes per entry. The worker retains its independent trust/resource/cancellation limits. Current case/whole-word/regex options are retained from Find; selection scope is cleared for folder search.

Native pointer, Tab/Shift+Tab, activation, clipboard/undo, dead-key/AltGr text and IME preedit/commit routes use the shared bounded TextField. Focus changes cancel uncommitted preedit. Candidate bounds follow the focused field's shaped caret. The accessibility owner wires modal group, focus and actions for IDs77000..77006; validation has an Alert node77007. Theme colors come from current UiTheme.

Added source regressions for safe defaults, real scope/query option propagation, invalid filters and cancelled preedit preserving the scope. Only child-file rustfmt parsing was performed; no Cargo/build, git or manual QA was run. Native reference inspection used the existing grouped-results screenshot as composition guidance; the additional configuration state and actual physical input/DPI behavior require later native acceptance. Existing replacement UI and search engine implementations were not edited.
