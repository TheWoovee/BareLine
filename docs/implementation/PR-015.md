## Delivered

`WindowsPathTrustProvider` rejects session/extension, UNC/device/ADS/parent traversal before destination access. Drive classification rejects mapped remote drives. Root-first no-follow handle checks reject reparse/offline ancestors before canonicalization. Explicit user local/removable reads/writes are eligible; execution is denied. `PathTrustProvider::open_read` returns `TrustedRead` holding final read handle and all ancestor handles with write/delete sharing denied. Consumers retain the guard and read that same handle, preventing namespace retarget between classification and read; plain PathTrust is only a classification. Folder/lifecycle consumers are coordinated in their PRs.

`WindowsWatchService` uses one idle-sleeping overlapped ReadDirectoryChangesW worker for up to 63 deduplicated roots, 64 KiB aligned buffers per root, 256 pending and 256 output events. It normalizes create/modify/remove/ordered rename halves, debounces for 50 ms with bounded latency under continuing traffic and coalesces adjacent duplicate modifications. Queue/OS overflow returns RescanNeeded. Cancellation signals an event, cancels and drains outstanding I/O before buffer/handle destruction. Failed watches emit RescanNeeded and reattempt trust-checked root setup on cancellable 250 ms waits; successful rearm emits another rescan notice. Setup keeps retained trust guards through opening overlapped handles.

`TailVerifier` accepts a captured full fingerprint. Each cancellable step reads at most 64 KiB, verifies the complete old prefix before accepting growth, and checks held/path identities. Prefix rewrite, truncation, rotation or concurrent metadata changes fail closed. Verification is constant-memory but O(full prefix) I/O. Verified fingerprints can open a fresh paged generation via `FileSource::open_verified_generation`; old Ready bytes are not changed. Follow-scroll pause is independent of ingestion; confirmed unlock stops following.
