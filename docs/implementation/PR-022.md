## Delivered

- `bareline-platform::SerializedPath` is serde-compatible version 1: `version`, `encoding` (`windows_utf16_le` or `unix_bytes`), canonical padded base64 `data`, and independent `display`. UTF-16 is encoded little endian. Native capture preserves unpaired surrogates/raw Unix bytes. `validate()` works on either identity on every host, bounds encoded input to 1 MiB, rejects malformed/noncanonical base64, odd UTF-16 lengths, NUL and unknown versions. `to_native()` rejects foreign encodings; labels never reconstruct identity. Session owns the JSON envelope/reload integration.
- Additive typed `Capability`, `Unsupported`, `PlatformReadiness`, and semantic modifier mapping. Existing `PlatformServices` signatures remain compatible. Primary maps to Control on Windows/Linux and Super on macOS.
- Linux/macOS `NativePlatform` adapters implement every current `PlatformServices` method. `open_file`, `save_file`, and `pick_folder` return explicit Unsupported errors. The legacy `about()` signature is void: it reports Unsupported to stderr; callers must query typed readiness before invoking it. This signature limitation is explicit rather than a successful native dialog claim.
- Each adapter tests shared shell operations through RecordingBackend while menus remain Unsupported.
- Shared `recording_probe_linux` / `recording_probe_macos` winit example source creates an event-loop window, normalizes DPI-adjusted pointer/focus/Enter/Space events into shared `UiEvent`, drives a shared button and records shared shell render operations on redraw. It records operations; it has no pixel painter. Creation failure exits with an error report. No desktop execution occurred while locked.
- Three-OS CI runs the workspace suites, including shared UI/layout/hit-test, document/search/session/syntax/settings/language tests as implemented, plus explicit example compilation. Linux installs winit system build dependencies. The architecture script inspects all neutral crates, dependency aliases/target sections and source Win32 imports/types; the only std Windows FFI exception is the private native path codec. Injected temporary manifest/source fixtures prove rejection. This conservative source guard is not a complete Rust parser or transitive dependency auditor.
