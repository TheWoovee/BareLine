# PR-008 — Source closure audit (2026-09-08)

This matrix supersedes the earlier foundation-only notes. Source is integrated through the current shared batch; the integration owner runs the combined gate. Controlled performance and native acceptance are separate evidence, not inferred from source or documentation.

| Requirement | Actual consumer and contract | Remaining evidence or limitation |
|---|---|---|
| Catalog and primary lexer | Fifteen FC-09 language entries have Lexilla bindings and validated native data definitions. Worker-owned `LexerSession` preserves ILexer5 across absolute-coordinate rolling windows. | Shared C-family binding is lexical coverage, not complete language-specific grammar parity. Exhaustive Notepad++ family parity audit remains external verification. |
| Opaque seek and cancellation | Resident worker and paged worker reconstruct forward from origin for primary requests. Missing retained lookbehind switches to verified native state; failures/cancellation poison the primary session. | An 8 MiB cumulative primary-session input ceiling bounds upstream private histories. No opaque checkpoint restoration or guessed blank-line state is claimed. |
| Bounded paged source | `Styling::refresh_paged` resolves actual `PagedReadHandle` pages off the UI thread; `StreamLexer` consumes newline-aligned windows <=256 KiB. `ViewportProjection` compares actual source bytes with the adapter before publishing local style runs. | Lines exceeding one bounded window remain unavailable. Primary cold seeks may require background replay; the UI remains readable as plain text. Controlled 1 GB/100 ms fallback-selection measurements are not yet recorded. |
| Identity and readiness | Real paged identity/revision, viewport origin, local snapshot and language/configuration identify each job. `StylingReceipt` reports real source range and current verified coverage for QA. | Receipt is implementation state, not a measured performance result. |
| Sparse native checkpoints | Native state is emitted every 256 global logical lines plus endpoints, including streamed windows. Resident styling retains at most 256 checkpoints and invalidates on source/revision/language/definition/preference changes. | Paged primary replay preserves bounded memory rather than pretending sparse integer states restore private Lexilla state. |
| Fold discovery | Lexilla fold levels, native brace/custom delimiters and native Python indentation feed `FoldAccumulator`; open headers survive windows. Worker results are bounded to 8192 folds and delivered progressively. Loss of opaque open headers remains explicitly incomplete. | No fabricated closing header at a truncated boundary. Fold quota cannot prevent already verified viewport styling. |
| Fold rendering and commands | Resident visual/logical maps consume folds in drawing, hit testing, scrolling and gutter input. Paged commands use global fold state; verified contained ranges project into the current window. Level policy continues as new metadata arrives, with independent cloned-view state. | Paged folds larger than the current window still need global skip/navigation rendering; selecting such a fold globally does not yet hide an arbitrary-size interval. |
| Fold edit/session anchors | Resident edit receipts and undo/redo preserve exact fold byte anchors until verified metadata rematches them. Session ranges are half-open logical lines. | Paged revision changes safely invalidate global folds; equivalent paged edit/undo anchor preservation is a separate editor-owner graft still required. |
| Detection and preferences | Explicit override, bounded workspace filename globs, filename, shebang/modelines and conservative content detection are ordered. Prefix/suffix reads are <=8192 bytes and work for real paged sources. Identity/path/association changes re-run detection. Persistent `language.policies` controls primary/native and PR-013 behavior. | No performance-based default preference change without measured evidence. |
| UDL pipeline | Bounded XML/JSON import reports imported/approximated/unsupported fields. Imported definitions are selectable and consumed by styling/folds. Native JSON editing validates on revision, previews an isolated sample, updates matching definitions, and exports atomically. Reviewed-byte import avoids path re-open races. | Unsupported source UDL features are reported, not silently interpreted. |

Staged regression coverage includes streaming multiline comments and global folds, byte-verified viewport projection, mismatched source rejection, cancellation poisoning, split-CRLF rejection, global 256-line checkpoints, and bounded association precedence. Earlier bridge/accessor cancellation and resident edit/fold tests are recorded in [PR-008-lexilla.md](PR-008-lexilla.md). Latest additions await the sole shared gate; no independent Cargo run or manual QA was performed for this batch.

PR-008 is not claimed fully closed while the two paged fold consumer limitations above remain. Native physical acceptance and controlled performance also remain unverified.
