# T02 root review R1 — changes required

Reviewed source base c3c13f19e377729809451739a4c5026302b3e16c through 33828a10fc9994a3912c6a68d17d2b5b944de9f2. Do not integrate yet.

1. **Profile authority on no migration/failure.** `migrate` returns an empty report when roaming is absent or roots coincide; `reconcile_profile_initialization` interprets every missing item as legacy and replaces valid local session/recovery/extensions/macros roots with absent roaming roots. Its error branch leaves recovery/extensions on local even if only legacy data exists. Use explicit per-item read authority determined before releasing readers, with no-op/missing-source states retaining correct local authority. Do not infer missing/unreadable from `Path::exists` (permission/I/O errors must remain errors). Regression: local populated + roaming absent, roaming unavailable, damaged journal with legacy populated, and partial item failure.

2. **Portable/diagnostics isolation.** prepare always populates legacy paths from roaming, and bootstrap now falls back to them in all launch modes. Restrict migration/legacy fallback to the installed mode. Verify portable empty settings/session never read the installed profile and diagnostic/perf modes retain their I/O contracts.

3. **Macro gate incomplete.** `macros_pump` still calls `load_library` from user_event and about_to_wait without settled gating; `macros_dispatch` can load as well. `set_profile_directory_before_load` then fails after empty local load. Gate actual runtime load/mutations and ensure completion schedules the newly enabled readers. Extensions manager commands can likewise run during migration and defeat its pre-restore root setter; audit all entrypoints, not only the Wake branch.

4. **Read and write authority must be separate.** MacrosRuntime.directory drives both load_library and save_library; ExtensionsRuntime.root drives inventory and mutations. Setting either to legacy on retry makes roaming a live write root, contrary to the documented sole local writer contract. Split bounded read authority from local mutation destination, and prevent edits from overwriting existing unimported data. Test failed migration followed by a user macro/extension action.

5. **Enumeration/depth budgets.** sorted_entries collects the entire directory before any Budget visit/check; an enormous directory is unbounded, and recursive traversal has no depth limit. Charge each enumerated entry with cancellation/time/count before collecting, and bound recursion or use iterative traversal. Test flat oversized and deep trees terminate as retryable with source retained and bounded memory.

6. **Ambiguous tree hash.** File content has no length delimiter and directory nesting no end delimiter. For two files a/b, moving an encoded b-name + file marker between a's tail and b's prefix can preserve the hash, total bytes, and entry count for different contents. Use canonical length-prefixed per-entry path/type/length/content-hash records (lossless names) and test this concrete equal-count/equal-total-size structural collision plus differing nesting.

7. **Retirement generation safety.** Held existing file handles do not prevent adding a new child to a Windows directory after enumeration. Moving that root may retire unverified new data from another live instance. Prove exclusive source generation authority, or retain source when uncertain; do not retire based only on hashes of enumerated children. Also source.exists()==false cannot by itself establish verified SourceRetired. Add a deterministic added-child-at-retirement hook and preserve both generations.

8. **Qualification is too simulated for Windows sharing contracts.** The five engine tests use a fake with no-op guards and remove-then-rename journal commits. Add focused native adapter tests for real file and directory publication/retirement, locked source retry, reparse rejection, and a partial/transition interruption restart. Root executes Cargo once source is corrected; no worker Cargo. Existing source-drift test mutates before the entire second migration pass, not at the guarded retirement boundary.

Keep the bounded settings revision check, retained recovery bytes and explicit per-item journal. Add a retry action connected to the actual maintenance owner (the brief requests an action; a transient restart string alone is insufficient). Coordinate notification presentation with later U02 instead of redesigning shell visuals.

9. The generic Windows open_sealed_read change from FILE_SHARE_READ to FILE_SHARE_READ|FILE_SHARE_DELETE weakens an existing identity/rename/delete contract and its sealed_read_denies_mutation_until_guard_is_dropped regression. Keep the generic primitive unchanged; use a narrowly scoped migration reader tied to its explicit held identity lease.
