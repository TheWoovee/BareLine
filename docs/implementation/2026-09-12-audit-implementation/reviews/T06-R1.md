# T06 root review — corrections required

Reviewed the prepared worker patch against baseline `3c7f4a1681d676b38b49192b594578b914222212` before acceptance. This is not an accepted commit.

1. `Task::cancel` only sets a flag. With a gated/queued job and no result, `poll` still returns Pending and no wake arrives until execution finishes. Require prompt terminal cancellation and owner notification while the gate remains closed.
2. `poll` blocks on the result-receiver mutex held by `wait_timeout`, violating its nonblocking contract. A waiter can also remove the result before it acquires the cancellation/consumption gate, while a concurrent poll observes Disconnected and consumes failure. Require linearizable observation or an explicitly single-consumer API, plus a barrier regression.
3. The new accessibility test calls only a cleanup helper; it does not establish that the asynchronous reader reaches cleanup on a failed/stale read. Require one meaningful scheduled-consumer regression.
4. Wake-count tests cannot infer notification completion from result receipt, since the result is sent first. Synchronize on the notification itself.

Returned to `sol_workers_impl`. Its initial contained task tests passed before corrections; the remaining accessibility/native checks were deliberately not run against known-incomplete code. Cargo was released for another lane. Re-review the corrected delta and repeat only affected checks.
