# T04 root review — actual command path and final cleanup authority

Reviewed rebased implementation `2fc245c180579b557ac68dd078f69c54f23fae5a` and R3 correction `3f0ac2241e13b220440da83865e2eae4fb02907d`. Changes requested; not integrated.

Selective tracked-open outcomes, verified-only content actions, multiple failed scan owners and real interrupted-cleanup retry address substantial earlier findings. The rebase preserves T18 outcome propagation. Remaining blockers:

1. Common precommit conflict comparison uses the target as the other version. That target is already open in the dirty editor, so the new already-open-path check rejects the normal Compare command. Open fresh action-owned snapshots, identified by their tracked receipts, without reusing the dirty tab. Exercise the actual shared command route; the new tests currently construct `PendingConflictAction` directly and bypass this rejection.
2. Next Conflict writes an explicit selection, but subsequent lookup always prefers the first conflict for the active target. The selected message and action owner disagree, and cycling can stick. Honor explicit selection within its active-document context and invalidate that context on tab change. Cover multiple conflicts for one target and switching between affected tabs.
3. An asynchronous failure of one Compare open drops the action while its peer may still be pending. The peer's later receipt has no consumer. Drain/cancel the remaining exact request IDs on terminal failure, just as the admission-failure path does.
4. Cleanup still deletes every state record before deleting the manifest. Failure at manifest deletion or process death in that interval leaves no durable cleanup decision; restart sees Unverified instead of a retryable cleanup. Keep a self-contained cleanup authority through the final destructive step and test the later failure window as well as interruption immediately after artifact retirement.
5. Reacquired cleanup ownership must verify the current durable cleanup record under the held directory authority; the earlier scanned state alone is not sufficient.
