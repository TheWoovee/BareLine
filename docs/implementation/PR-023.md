## Form and palette foundation slice (2026-09-06)

Read the PR brief, FC-09, shared chrome/keyboard interaction rules and current `bareline-settings.png` / `bareline-command-palette.png` references before adding paint code. No desktop automation, new dependency, commit or remote operation was used.

- `focus::{FocusChain, FocusTarget}` implements declared traversal order, disabled/hidden focus removal, nested active layers and invoker focus return. It is an additive model; consumers still need to route native Tab/Shift+Tab and popup lifetime to it.
- `widgets::{List, ItemSource}` queries only visible uniform-height rows plus one row of overscan. Selection supports arrows/Home/End, skips disabled rows, reveals the selected row and emits typed actions. Unknown totals use the discovered prefix. The variable-height and lazy-tree contracts remain separate unfinished work.
- `Combo` adds bounded committed-text prefix search (256 bytes, one-second reset, at most 4096 form choices), open state, Escape selection restoration and semantic expanded/value state. Owners provide header/popup geometry and route committed text rather than preedit into search.
- `Checkbox`, `RadioGroup`, `Slider`, `Stepper`, `Splitter` add keyboard/pointer behavior, disabled checks, paint and semantic descriptors. Numeric ranges reject nonfinite bounds/steps; steppers retain invalid input in the owner; slider/splitter drags terminate on focus loss.
- `widgets::{Theme, Metrics}` supplies semantic paint colors and compact/comfortable logical metrics. No RGB literals occur in widget code. The default uses existing dark chrome tokens; light/high-contrast theme integration and full golden coverage are not claimed.
- Additive `Semantics` records include an explicit localized name, stable command ID, role, committed value, bounds, state, validation reason and available actions. Existing Button/TextField/Scrollbar adapters preserve the original public structs. TextField semantics exclude IME preedit. PR-024 still owns the platform accessibility bridge.
- Fixed two consequential primitive bugs: fractional row offsets now include the partly visible bottom row without relying on overscan; disabled buttons clear stale focus/pressed state on focus loss.

## Lazy data, routing and text modes follow-on (2026-09-06)

- `virtual_tree::{Tree, TreeSource, NodeId, TreeAction}` stores expanded branch metadata, never a flattened tree. Indexed child lookup permits direct viewport seeking across one million siblings; nested expansion/collapse maintains row counts. Unknown child counts emit `RequestChildren` for owner background discovery. Sources must use a resident index, and owners reset paths after source reorder. Expansion depth is bounded to 64. Selection, reveal, arrows/Home/End, activation, pointer expansion and selected-node semantics are implemented.
- `variable_list::{VariableList, VariableItemSource}` uses owner-provided indexed `index_at`/`offset_of` geometry for nonuniform heights and unknown totals with a discovered prefix. Paint/hit/reveal share geometry, overscan is bounded, and corrupt/tiny row metrics cannot emit over 4096 rows per call.
- `focus::{EventRouter, RouteTarget, DispatchResult}` implements popup capture, focus, hit target and ancestor order, stops at handled events, returns invalidation regions and releases pointer capture on release/focus loss. Malformed ancestor cycles terminate.
- `overlays::{AnchoredPanel, Tooltip, Banner}` provides sticky explicit dismissal, one-shot tooltip deadlines without an idle timer loop, clipped paint, semantic records and keyboard/pointer banner dismissal. Owners still compose and route them.
- `text_field::TextMode::{Text, Password, Decimal}` is additive. Password masking uses one bullet per grapheme, maps shaped hit positions back to whole graphemes and suppresses selected clipboard text/semantic cleartext. Decimal mode filters the complete candidate before mutating history; invalid IME commits cancel preedit without an undo entry. Placeholder and validation reason APIs are available. Existing default field behavior/API is preserved.
- `controls::{ScrollbarInteraction, ScrollAction}` adds page/step navigation, drag preview versus commit, deferred-drag cancellation on focus loss, and bounded unknown-total refinement. Refinement reports whether another owner-driven update is required and does not run a timer.

Final focused evidence: `cargo test -p bareline-ui` passed **16 tests** (10 unit + 6 integration, 13 added across these slices). New tests cover lazy nested expansion and million-sibling seek, unknown-child requests, nonuniform hit/reveal, routing order, password grapheme deletion/semantic isolation, invalid numeric composition history, sticky/banner/tooltip lifecycle, deferred scrolling cancellation and extent refinement bounded by one old thumb height. `cargo clippy -p bareline-ui --all-targets -- -D warnings` and focused `rustfmt --edition 2024 --check` on the touched control modules/test passed after the final changes. No new dependency or lock-file edit was needed by this lane. Full light/dark/high-contrast screenshot goldens and actual composed-screen equality remain outstanding; these structural checks do not establish either.
