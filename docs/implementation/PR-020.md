## Concrete findings and source-verified resolutions

1. **Prefix data masquerading as a complete saved state:** different builder prefixes originally reused revision/content identity. Builder appends now advance state/revision; prefix snapshots are incomplete, and save/mark-saved/diff apply reject them.
2. **Malformed session identity bypassing fallback:** invalid base64/UTF-16 paths originally passed manifest validation. Canonical path validation now rejects those primaries, allowing the previous manifest to recover.
3. **Codec metadata rewriting provenance identity:** public encoding overrides originally controlled raw-copy compatibility. A private immutable original encoding now controls raw-copy and opaque-conversion refusal.
4. **Recovery silently rolling back a durable checkpoint:** a journal truncated at a valid record boundary could look complete. Scan now marks a journal below the checkpoint watermark corrupt. Baseline-backed inverse-prefix replay also rejects records that hash correctly but cannot apply, preventing a false Complete label.
5. **Memory amplification in process output and placeholders:** one-byte output chunks could accumulate excessive metadata, and repeated selection placeholders allocated before checking size. Output now accounts for entry overhead and caps entry count; each argument append checks its remaining budget first.
6. **Extension edit-list memory amplification:** compact postcard vectors could expand millions of edits before validation. A bounded visitor rejects excessive counts before vector allocation and is shared by direct and staged edit decoding.
7. **IPC deadline bypass while making progress:** timeout was checked only after no-data responses. Read/write loops now check deadlines before every OS operation.
8. **Uninterruptible WASI or component compilation:** epoch interruption alone did not bound a blocking host poll call, and compilation preceded the watchdog. Compilation now runs after watchdog startup; an unresponsive optional host exits after the grace period.

The final host executable/supervisor received a further source review: held Authenticode/hash-verified handles survive launch, the authenticated invocation fixes extension identity/grant generation, and every guest frame is checked against that identity before broker dispatch. No additional concrete blocker was found in that production path. Separate-process behavioral evidence is still required.

Related data-safety fixes were also reviewed in dependency slices: diff preserves logical EOL separators and validates ranges before length arithmetic; power edits retain blank rows and unselected tab columns and check tab expansion before allocation. These are supporting evidence, not substitutes for PR-020 acceptance cases.
