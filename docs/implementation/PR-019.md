# PR-019 implementation evidence

Status: IN_PROGRESS. Implemented the deterministic, headless resident/paged source benchmark entry point `cargo xtask perf document`. It exercises metadata open, first bounded editable window, one transaction and an absent-literal full source scan. The scan is explicitly harness traversal, not product search-engine throughput. Per-run source byte counts, page requests, budget reservations and process private-byte point samples distinguish bounded work from timings.

The generated ASCII fixture uses constant 64 KiB construction storage and lives only in the ignored results directory; no user source is modified. Resident comparisons are omitted above the existing 256 MiB policy. Paged 1/5 GiB runs are explicit opt-in commands. Results retain nulls for unmeasured frame/full-load/working-set metrics. Private bytes cover xtask, not editor idle or peak process memory.

Neither renderer defaults nor resident threshold are changed without comparative data. Launch/scroll/paint, syntax/search-engine cancellation, workspace scan, tail/save, 100/500-tab and extension-process totals, paired Notepad++ P50/P95 and nightly regression expansion remain outstanding.
