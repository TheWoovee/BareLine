## Persistent contracts and limits

Session JSON remains versioned and bounded; MRU paths use the existing lossless SerializedPath format. Recovery metadata gains a defaulted optional original_path (display/compare origin, never a save target). Each successful root publication also retains a version-1 root-N.receipt.json for validated corrupt-tail recovery. Recipes are bounded to 65,536 pieces and 128 MiB, with retained structural memory charged. Recovery never masquerades as a saved user file: restored documents require Save As.

Atomic replacement still documents the residual arbitrary external-writer race; no filesystem compare-and-swap claim is made. Native sealed read handles deny write/delete while consumed. Storage errors preserve current edits and expose the last durable recovery status rather than claiming protection that did not complete.
