## Final closure source wave

`paged_typing::prepare` supplies bounded, cancellable plans for the existing paged actor, reusing resident pair, indentation and comment policies. Huge pair/block wrapping uses two boundary edits in one transaction; it does not copy selected bytes. Plans carry the intended global caret, and closer overtype returns no history edit. Line-comment context is bounded and refuses unavailable complete lines. The editor-owner enqueue/actor graft remains required to make these plans live.

Native completion acceptance now checks real source and projection identities, resolves both replacement edges through the shared source map, and rejects replacements crossing a hidden interval. Signature hints remain available on a verified contiguous logical-line prefix within any visible piece. A prefix crossing a hidden join, an offscreen caret, or an unverified partial first line is suppressed; both automatic hints and completion-attached hints apply this guard. Staged tests cover huge wrapping without reads, pure overtype, cancellation and invalid source windows. They await the combined gate; no separate checks were run.
