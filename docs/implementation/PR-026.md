Status: source integration in progress; coordinator verification pending.

The native replacement workflow captures a mixed folder/workspace preview, shows per-file and per-match before/after excerpts, requires reviewed inclusion before Apply, and keeps open documents unsaved. Changing preserve-case, binary inclusion or per-job backup choices invalidates the preview. Refresh rebuilds it. Regex captures are expanded during preparation; case preservation applies uniform upper/lower or initial capitalization, leaving mixed case literal. Backups default on and live in the receipt folder; explicit disabling resets after submission.

Resident single edits and paged edits report counts from actual actor terminal receipts. Multiple resident edits use the existing SurfaceGroup coordinator. Paged selected edits stream inverses and inserted text into sealed owned sources, validate a PreparedSourceTransaction on the worker, then use the journal-owning actor's tracked source transaction dispatcher. Closed paged files use the same bounded staging before atomic codec-preserving save. Identity/full fingerprints and open-file admission are revalidated. Receipt states survive interrupted commits and rollback, and rollback refuses changed targets or backups. Original size also selects the paged rollback path, so a large original shrunk to a tiny result remains restorable.

Cancellation retains worker tickets until terminal acknowledgement, clears untouched queued files, and preserves committed disk/open counts and receipt details. No revision-change heuristic counts a successful single edit.
