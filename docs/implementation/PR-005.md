# PR-005 — Search and replace

State: IN_PROGRESS. Started from the own PR brief and FC-05/06 only; dependency interfaces read where needed. This first slice implements a bounded case-sensitive literal scanner over immutable Resident snapshots, with explicit terminal completeness, cancellation, capped streaming results and stale-safe single-document replacement preparation. No additional dependency is needed.

The scanner carries prefix state across rope chunks instead of concatenating windows, including long lines. Pattern bytes and result storage have hard limits. Empty patterns and unsupported modes return explicit errors. Default Unicode 17.0.0 full case folding is generated offline from pinned official data with its license preserved. A bounded scalar-offset ring maps expanding folds back to complete original scalars; partial scalar replacement is prohibited. Regex/PCRE2, paged sources, folder scanning, linked replacement, marks and search UI remain subsequent work; do not claim full PR-005 acceptance from this slice.
