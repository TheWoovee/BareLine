# Bareline user guide

This guide describes the Windows x64 preview as it is on the current `master` branch. Bareline is a preview: read [Known issues in this preview](../../README.md#known-issues-in-this-preview) before relying on it for important work, and keep independent backups.

Every command named here can also be found by name in the **Command Palette** (**Ctrl+Shift+P**). Shortcuts are those of the default Bareline preset unless a page says otherwise.

| Page | What it covers |
| --- | --- |
| [Install and portable mode](install-and-portable.md) | Installer, portable ZIP, where the profile lives, uninstalling, upgrading. |
| [Recovery](recovery.md) | What is protected, where recovery journals live, restoring and discarding recovered work. |
| [Large files](large-files.md) | Large-file (paged) mode, line counting, and what is limited in that mode. |
| [Search, replace and regular expressions](search-and-regex.md) | Find modes, regular-expression semantics, replacement syntax and limits. |
| [Replace in Files](replace-in-files.md) | Folder and workspace replacement, the review preview, backups and rollback. |
| [Compare](compare.md) | Comparing documents and versions, options, copying changes, limits. |
| [Macros and external commands](macros-and-external-commands.md) | Recording and playing macros, Run (F5), external command definitions and their security model. |
| [Encodings](encodings.md) | Detection, **Interpret As** versus **Convert To**, byte order marks and line endings. |
| [Keyboard presets](keyboard.md) | The Bareline and Notepad++ shortcut presets and the Shortcut Mapper. |
| [Spell check](spell-check.md) | What is checked, suggestions, dictionaries. |
| [Troubleshooting](troubleshooting.md) | Startup problems, diagnostics logs, reporting a bug with the build commit. |

Coming from Notepad++? Read [Coming from Notepad++](../coming-from-notepad-plus-plus.md) first.
