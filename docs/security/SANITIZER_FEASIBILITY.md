## Enforced boundary contracts

- Lexilla exports in `native/lexilla-bridge/src/bridge.cpp:139,179,203,224,227` are `extern "C"` and `noexcept`; each catches exceptions, with cancellation/unavailable mapped to explicit result codes. The Rust callback at `native/lexilla-bridge/src/lib.rs:147` catches unwind and returns cancellation. The owning session wrapper frees once; caller-owned slices remain alive through synchronous calls. C++ probe and ordinary bridge tests exercise boundary rejection, but are not sanitizer runs.
- PCRE2 in `crates/search/src/regex.rs:18` declares the missing callout ABI from pcre2.h. Callback data points to a stack Interrupt held through synchronous matching; callback reads cancellation/time only. Engine Drop frees exclusive native allocations; table/ovector accesses rely on PCRE2-owned storage while its owner is live. `pcre2-sys = 0.2.10` is pinned. Instrumenting only the Rust wrapper does not instrument a prebuilt/system PCRE2 library.
- Windows callbacks (including the checked-in AccessKit fork) are `extern "system"`; Rust unwinding must never be relied on across those frames. Release workspace profile has `panic = "abort"`. Safe failure results are preferred; a panic at a non-unwind ABI boundary terminates rather than constituting successful recovery. The inventory records caller obligations for window lifetime, COM references, callback data and thread affinity.
- COM provider ranges use owned interfaces/Weak lifetime tokens, not unchecked foreign-provider downcasts. SAFEARRAYs own inserted interface references and destroy partial arrays on failure. Native HWND/MSG inputs must originate from the live owning window callback; OS APIs are outside the Rust memory model checker.
