# Bareline Editor - Security, Leak and Crash-Safety Review

Root: `D:\Notepad_REq\Bareline_Product_Blueprint\Bareline-Editor` (Rust workspace, x86_64-pc-windows-msvc only).
Release profile: `panic = "abort"`, `lto = "fat"`, no `overflow-checks` (Cargo.toml). Consequences used throughout:
- any panic == immediate process death, unsaved edits lost (the panic hook in `crates/diagnostics` only writes a log line; there is no emergency-save path);
- `usize` underflow wraps silently and only crashes if the wrapped value is later used to slice/index.

Method: every `unsafe` block in `crates/platform-windows` and `crates/renderer*` was read; IPC/update/extension/file-IO/command/regex paths were read end to end; non-test `unwrap/expect/index/slice/sub` sites were enumerated with ripgrep and the risky ones read; leak primitives and caches were grepped and traced. Only findings verified in source (and, for CRASH-01, reproduced on the project toolchain rustc 1.98.1) are listed. `cargo deny check advisories` was run (cargo-deny 0.20.2): **ok**.

Severity legend: Critical = reproducible abort/compromise from ordinary user input; High = abort or persistent loss of function reachable from normal use; Medium = needs an unusual but plausible precondition or is defence-in-depth against an attacker-supplied file; Low = hardening / latent.

## Verified clean (coverage record)

**Unsafe / FFI (`crates/platform-windows`, `crates/renderer*`)**
- `native.rs`: HICONs from embedded ICO destroyed on drop; popup menus destroyed after `TrackPopupMenu`; `CoTaskMemFree` after every `GetDisplayName`; HMENU ownership transferred to the window via `SetMenu` (destroyed with the HWND) with `SetMenu(None)+DestroyMenu` on failure; `registry.state(..).unwrap()` in `context_menu_in` is safe (specs come from `registry.entries()`); all `PCWSTR` inputs are NUL-terminated owned `Vec<u16>` alive across the synchronous call.
- `menu_bar.rs`: subclass removed before state freed; GDI font/brush deleted on replace and drop; items are `Box<Item>` so `dwItemData` pointers are stable; `text[..len-1]` always valid (vector always NUL-terminated).
- `clipboard.rs`: `GlobalAlloc/Lock/Unlock` paired; `mem::forget` only after successful `SetClipboardData` (correct ownership transfer, failure path frees); 4 MiB cap; NUL scan; `GlobalSize` validated before `from_raw_parts`.
- `printing.rs`: PRINTDLG `hDC/hDevMode/hDevNames` freed on every path; DEVMODE `dmSize+dmDriverExtra` validated; `tab_width` validated 1..=16 before `width - column % width`; all `&text[a..b]` slices use char-boundary-validated spans.
- `process.rs`: `CREATE_SUSPENDED` -> kill-on-close job -> resume; failure path kills+waits; toolhelp snapshot handle owned.
- `watch.rs`: OVERLAPPED boxed; `CancelIoEx` + `GetOverlappedResult(wait=true)` before free; 16 KiB buffer; 63-directory cap; `sync_channel(256)` + overflow -> `RescanNeeded`.
- `renderer.rs`: `MAX_LAYOUTS` cap; per-frame image bitmaps dropped at frame end; swap-chain target released (`SetTarget(None)`) before `ResizeBuffers`; device loss clears brushes/target; all COM via `windows-rs` smart pointers.
- `accessibility/*.rs`: SAFEARRAY destroyed on `SafeArrayPutElement` failure; every lock is poison-tolerant; every UIA entry re-validates source identity, selection offsets, and `text_geometry` (<= 4096) before use.
- `rename.rs`: `FILE_RENAME_INFO` storage sized `max(struct, offset+name)`, u64-aligned, NUL tail; basename rejects `\0 / \`.
- `update.rs` `create_private_stage`: token/descriptor `LocalFree`d and `CloseHandle`d on all paths; `BCryptGenRandom` names; user-only DACL.
- No `SetTimer`, `SetWindowsHookEx`, `RegisterClass`, `CreateFileMapping`/`MapViewOfFile` or `memmap2` use in first-party code (memmap2 is transitive via wasmtime only), so "file shrinks under mmap" is not applicable; paged reads use `read_exact` with `FileIdentity` re-checked before and after each page (`source.rs:113-172`) -> `FileError::Changed`.
- No `Box::leak` / `mem::forget` / `ManuallyDrop` / `into_raw` in non-test code other than the clipboard ownership transfer above.

**IPC / single instance / CLI / update**
