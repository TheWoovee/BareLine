# Changelog

All notable changes to Bareline are documented in this file.

The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/). Preview releases are tagged `v<version>-preview.<date>[.<n>]`. During the preview, versions do not promise [Semantic Versioning](https://semver.org/) compatibility. Entries name the review IDs of the fixes they describe; the matching commit subjects carry the same IDs.

## [Unreleased]

Entries are grouped by area within each section. Code changes were merged with automated tests; acceptance on clean machines is still pending ([docs/STATUS.md](docs/STATUS.md)).

### Added

- **Languages:** syntax highlighting for 51 more languages, for 66 in all. Bareline now bundles every Lexilla 5.5.3 lexer and adds PowerShell, Batch, Shell (Bash), YAML, Markdown, INI, Properties, PHP, Perl, Ruby, Lua, Makefile, Dockerfile, CMake, Diff, Log, Visual Basic, VBScript, Pascal, Fortran, Assembly, LaTeX, R, Swift, Kotlin, Scala, Groovy, Dart, Haskell, Erlang, Tcl, AutoIt, NSIS, Inno Setup, Registry, SCSS, Less, Ada, D, F#, Julia, Lisp, MATLAB, Nim, OCaml, Verilog, VHDL, Zig, CoffeeScript and GDScript. Files are also recognized by names such as `Makefile`, `Dockerfile` and `CMakeLists.txt`, and by `#!` interpreter lines. (BIZ-03)
- **Encodings:** ISO-8859-2 to ISO-8859-16 (except -9 and -11, which Windows-1254 and Windows-874 cover), KOI8-R, KOI8-U, Windows-874 (Thai), Mac Roman, Mac Cyrillic and the DOS code pages OEM 437, 850, 852 and 866. **Encoding > Interpret As** and **Convert To** list Unicode first, then one submenu per region or script. These encodings are never detected automatically; choose them explicitly. (BIZ-09)
- **Tools:** JSON, XML and Hex tools are built in, under **Tools > JSON, XML and Hex**: Format, Minify and Validate JSON; Format and Validate XML; XPath Query with the line and column of each match; and Hex View, a read-only tab of a saved file's original bytes. The tools work on the selection or the whole document off the editor thread, format as one undoable edit using the indentation settings, and move the caret to the line and column of the first error. Bareline 1.0 ships without third-party plugins. (BIZ-04)
- **Spell check:** misspelled words in plain text and Markdown are underlined using the Windows spelling dictionary for your language, with up to five suggestions, **Add to Dictionary** and **Ignore All** in the context menu and **Edit > Spelling**. Code is checked only when its language turns it on, and then only in comments and strings. (BIZ-31)
- **Keyboard:** a Notepad++ shortcut preset beside the Bareline one, offered on the first launch of a new profile, in **Settings > Keyboard > Shortcut preset** and under **Settings > Import from Notepad++**. Your own shortcut changes are kept when you switch. (BIZ-08)
- **View:** Zoom In, Zoom Out and Restore Default Zoom (Ctrl+=, Ctrl+-, Ctrl+0 and the keypad keys), Word Wrap, Line Numbers, Show Whitespace, Show End of Line, Show Indent Guides and Show Edge Line toggles, Full Screen (F11), Always on Top, brace highlighting with Go to Matching Brace (Ctrl+B) and Select to Matching Brace (Ctrl+Shift+B), and Column Selection Mode. (BIZ-07)
- **View:** a horizontal scroll bar for long lines, in the normal editor and in large-file mode, with dragging, paging and Shift+wheel. (EDT-28)
- **Editing:** Insert toggles overwrite mode, shown as OVR in the status bar. (UI-07)
- **Files and tabs:** Close All, Close Others, Close Tabs to the Left and to the Right, Copy Full Path, Copy File Name, Copy Directory Path and Rename, in **File** and on the tab context menu. (UI-04, BIZ-28, WSP-01)
- **Files and tabs:** named sessions (**File > Recent Files > Load Session…** and **Save Session As…**), pinned entries and a Recent Folders list, and **Open in New Instance** and **Move to New Instance** for saved documents. (BIZ-07, WSP-01)
- **Files and tabs:** an all-tabs list when the tab strip overflows; Settings and Extensions open as tabs. (UI-05, UI-08, UI-09)
- **Files and tabs:** files dropped on the window open as documents, and a dropped folder opens as the workspace. (APP-05)
- **Command line:** `-` reads standard input into an Untitled document; the Notepad++ switches `-n<line>`, `-c<column>`, `-ro`, `-multiInst`, `-nosession` and `-noPlugin` are accepted and `-notabbar` is ignored; a path that does not exist opens as a new document that is created when you save it. (APP-09)
- **Replace in Files:** **Manage Replace Backups…**, **Delete Selected Replace Backup** and **Delete Old Replace Backups**; jobs interrupted by a crash are reconciled at the next start and offered for rollback; old jobs are retired automatically (the newest 20 finished jobs are kept, for at most 30 days). (SRC-09, SRC-11)
- **Search:** a **. matches newline** toggle in the find bar and a matching **Search > Options** command for regular expressions. The option is recorded in macros and applies to current-document, open-document and folder searches. (SRC-02)
- **Encodings:** an "encoding may be wrong" hint in the status bar, naming up to three likely encodings, when a legacy file could not be identified with confidence. (FIO-05)
- **Clipboard:** rectangular copies interoperate with Notepad++ and Visual Studio column blocks in both directions. (UI-15)
- **Privacy:** the **Add opened files to Windows Recent items** setting, which also covers the Open and Save dialogs, and a [privacy policy](PRIVACY.md) linked from About and the installer. (SEC-19, BIZ-24)
- **Documentation:** a [user guide](docs/user-guide/README.md), [Coming from Notepad++](docs/coming-from-notepad-plus-plus.md), [status](docs/STATUS.md), [Notepad++ parity and competitor](docs/PARITY.md) pages and a [roadmap](ROADMAP.md); the README describes how Bareline differs, labels each feature area Stable, Preview or Experimental, and lists the known issues of this preview. (BIZ-02, BIZ-11, BIZ-14, BIZ-16, BIZ-17, BIZ-26, BIZ-27, QA-14)
- **Distribution:** a Scoop manifest for the portable ZIP in `packaging/scoop`; it is not yet in a public bucket. (BIZ-13)

### Changed

- **Search:** regular-expression `^` and `$` now match at every line boundary by default, as in Notepad++. Start a pattern with `(?-m)` to anchor at the document start and end instead. (SRC-01)
- **Run (F5):** a program can be named by its absolute path or found on `PATH` (never in the current folder), the resolved program is shown for confirmation before it runs, and the Notepad++ variables `$(FULL_CURRENT_PATH)`, `$(CURRENT_DIRECTORY)`, `$(FILE_NAME)`, `$(NAME_PART)`, `$(EXT_PART)`, `$(CURRENT_WORD)`, `$(CURRENT_LINE)`, `$(CURRENT_COLUMN)` and `$(NPP_DIRECTORY)` are supported. The `PATH` lookup runs in the background and can be cancelled. (BIZ-27, SEC-10)
- **Rendering:** Bareline draws in software by default, which shows the first frame sooner and uses less memory than hardware drawing. `--hardware` or the **Drawing mode** setting selects Direct2D hardware drawing, which now starts after a first frame drawn in software. Background worker threads start when they are first needed instead of at launch. (PERF-02)
- **Startup and sessions:** files named on the command line or handed over by a second launch now open on top of the restored session, and the session is never saved before it has been restored. Only an explicit open or restore activates its tab, so session files that finish loading no longer take focus. A launch opens the first 16 files and lists the rest as not opened, instead of refusing the whole launch. (APP-06, APP-07, APP-09)
- **Files:** opening a binary-like file shows a notice above the document with **Edit as text** and **Close**, instead of a pop-up menu. The notice has its own band, so it no longer covers the first lines. (UI-01)
- **Files:** a file open that fails keeps its tab with the error and offers **Retry** and **Open read-only (large-file mode)**. Opening the same path again reuses that tab. (FIO-01)
- **Status bar:** six groups that keep their order at narrow widths; the size group shows the file's size on disk and whether the line count is complete; large-file indexing progress moved there from text painted over the document; encoding names are spelled consistently. (UI-02, UI-06, UI-07)
- **Notices:** the external-change and follow banners get their own band under the tab strip instead of covering it, lead with the file name, show the full path as a tooltip, and no longer duplicate themselves as a toast. (UI-02)
- **Menus:** every command has a place in the menus or the Command Palette, raw internal labels are gone from the menus, recovery, retry and conflict commands appear only when they apply, update and extension commands are hidden in builds that cannot use them, and the File menu is kept to 14 rows. (UI-04, BIZ-28)
- **Messages:** errors are shown in plain language instead of internal identifiers such as `BudgetExceeded` or `WrongDocument`. (UI-03, APP-02, APP-21)
- **Dialogs:** Save As keeps a file's exact name (a `Makefile` stays `Makefile`) and exports offer their own file type; the Save All prompt lists at most 15 names and says **Save** for a single document; the print preview shows the document's own pages. (UI-11, UI-18, UI-21, APP-20)
- **Fonts:** when Cascadia Mono is not installed the editor falls back to Consolas and then Courier New, never to a proportional font; fonts installed while Bareline runs appear in the font list. (UI-10, UI-20)
- **Macros:** a macro playback is undone with one Undo, in the normal editor and in large-file mode. (WSP-09)
- **Large files:** Replace All refuses more than 10,000 replacements before changing anything, with a readable message, and a single command acts on at most 1,024 selections and 4,096 edits. (EDT-02, PED-17)
- **Accessibility:** selected rows in lists, the palette and popups have their own highlight colors and a cue that does not rely on color, and the focused Documents list has a focus ring. (A11Y-01)
- **Localization:** command titles and menu captions come from an English resource table, and the interface language setting follows Windows. No translations are included yet. (BIZ-30)
- **Packaging:** preview executables include the C and C++ runtime, so the Microsoft Visual C++ Redistributable is no longer needed. About, `--version` and **Copy diagnostics** show the version and build commit, with links to the repository and the security policy. (BIZ-06, BIZ-12)
- **Project:** issue forms, including a data-loss form, a pull request checklist, code owners, maintainers, support, this changelog, the Contributor Covenant 2.1 and an AI-assisted development policy. The native UI journeys run nightly with a published readiness ledger ([docs/qa/READINESS.md](docs/qa/READINESS.md)); release-mode tests, feature coverage, fuzzing and a performance comparison harness run on schedules. (BIZ-20, BIZ-21, QA-02, QA-04, QA-05, QA-10, QA-14, PERF-01)

### Fixed

- **Recovery:** a failed or unqueued checkpoint of a normal document could clear the only durable checkpoint, leaving nothing to recover. (REC-01)
- **Recovery:** startup no longer deletes recoverable journals. Journals that cannot be read are listed so they can be deleted deliberately, instead of being removed silently. (REC-02)
- **Recovery:** recovery journals from separate instances (`--new-instance`, `--no-session`, `--no-extensions`, or a failed handoff), and journals whose process ID was reused after a restart, are now offered in the Recovery Center. (REC-02, REC-03)
- **Recovery:** reloading from disk or using **Interpret As** on an edited document now discards its old recovery data and history the same way closing does, so recovery no longer fails for the reloaded document, and a reload keeps the tab in place. The confirmation now asks to reload rather than to close. (REC-04, REC-15, WSP-11, PED-23)
- **Recovery:** signing out of or shutting down Windows with unsaved changes now writes the session and recovery checkpoints first, and Windows shows why Bareline is delaying shutdown. (REC-05)
- **Recovery:** after an internal error, Bareline waits up to 3 seconds for queued recovery checkpoints to finish before it exits, and records the outcome in the crash log. (REC-06)
- **Recovery:** large-file journals are written in order with their restore data, so a crash between the two falls back to the previous checkpoint instead of failing; checkpoints write only what changed instead of rewriting all inserted text; inspecting a journal no longer replays it into a full copy; and temporary files left by a crash are cleaned up. (REC-07, REC-08, REC-09, REC-10, REC-11, REC-12)
- **Recovery:** a journal with a damaged manifest can be discarded, a bad cleanup record no longer hides the other recoverable saves, and **Compare with last saved** on a large file no longer affects the live document's recovery. (REC-13, REC-14)
- **Recovery:** Undo and Redo are never refused because the recovery journal could not be written. (FIO-03)
- **Startup:** Bareline no longer exits without a message at startup. A damaged, oversized or UTF-16 `settings.toml` is set aside or converted with a notice and the editor starts with defaults, drive-relative paths such as `C:notes.txt` open, and a missing `APPDATA` or `LOCALAPPDATA` no longer disables recovery. `--help`, `--version` and argument errors are shown in the console or a message box. A launch that hands its files to a running instance leaves the settings file alone. (APP-01, APP-02, APP-16, APP-17)
- **Startup:** handing files to a running window is exactly-once and no longer times out while that window starts or shows a dialog, several launches at once are served, and two spellings of the same portable folder share one window. (APP-03, APP-04, APP-14)
- **Startup:** the first frame follows the Windows light or dark mode; a portable copy on read-only media warns once, exits with one close and keeps recovery journals in a local folder; the recent-files list and legacy settings are no longer read or written on the UI thread. (APP-11, APP-12, APP-13, APP-15, APP-19)
- **Rendering:** a drawing error is reported once as a notice instead of an endless series of message boxes, every graphics device loss is recovered, and a transient hardware failure no longer pins software drawing for the session. (APP-08, UI-12)
- **Files:** ordinary UTF-8 files with accented or CJK text open in the normal editor instead of failing, and a file that exceeds the in-memory budget falls back to large-file mode, including on reload. (FIO-01)
- **Files:** files on removable drives, non-NTFS volumes (exFAT, FAT32, ReFS), OneDrive folders, junctions and hard-linked files open and save, with a notice when saving there is weaker than on local NTFS. Network files open through **Open Remote File with Permission** and can be kept with **Save Copy**. (FIO-18)
- **Files:** a cancel that arrives after a save succeeded is no longer reported as a conflict, Save As keeps the path as you typed it instead of a `\\?\` form, and converting line endings in a selection that starts or ends inside a CRLF no longer produces stray CRs. (FIO-10, FIO-11, FIO-16, FIO-17)
- **Files:** a growing log can be opened in large-file mode and followed without being reported as changed, and following no longer rehashes the whole file or keeps a store per append. (FIO-04, FIO-13)
- **Files:** converting line endings works on files with more than 131,072 lines. (FIO-12)
- **Files:** saves have their own worker and no longer wait behind opens or long encoding conversions; legacy-encoded files decode in bulk; saves hash and copy the file far fewer times. (FIO-02, FIO-07, FIO-08, FIO-09, FIO-14, PERF-03)
- **Files:** a failing or untrusted folder no longer stops file watching for all other files; it is retried with backoff, and folders that cannot be watched are polled. (UI-16)
- **Encodings:** GBK and Big5 text are detected instead of opening as EUC-KR or Windows-1252, and UTF-16 without a byte order mark is detected instead of opening as binary. (FIO-05, FIO-06)
- **Editing:** typing after Home stays separately undoable, Undo and Redo reach the saved state, and a large edit under memory pressure drops the oldest undo history instead of being refused. (EDT-01, EDT-03, EDT-09, EDT-16, EDT-26)
- **Editing:** Replace All on large documents stays one undo step and reports refusals in readable text instead of stopping at "Preparing replacement...". (EDT-02)
- **Editing:** the 4 MiB limit on Windows clipboard copy and paste is lifted. The limit is now the `clipboard.max_bytes` setting (1 GiB by default), with a warning above 256 MiB. Pasting or cutting tens of megabytes works, an empty or non-text clipboard is ignored, a busy clipboard is retried, and search and other single-line fields accept at most 16 KiB. (EDT-07, UI-14)
- **Editing:** Move Lines, Duplicate and Indent keep the selection on the moved text, rectangle Delete no longer pads short lines, arrow keys move every caret, no-op transforms no longer mark the document modified, line operations use the document's line ending, and one failed edit no longer discards the queued keystrokes. (EDT-04, EDT-08, EDT-12, EDT-13, EDT-14, EDT-23, EDT-24, EDT-25, EDT-27)
- **Editing:** Backspace, Delete, Enter and Add Caret on very long lines no longer read the whole line, and editing with word wrap or folds no longer makes the view jump, flash "Preparing line" or briefly unfold. (EDT-05, EDT-06, EDT-17, EDT-18, EDT-19, EDT-20, EDT-21, EDT-22)
- **Editing:** hidden lines and bookmarks stay on their text when lines are inserted above them. (EDT-10, EDT-11, EDT-15)
- **Large files:** in large-file mode, rectangular selections, Shift+navigation anchors, auto-pairing, overtype, and line commands at UTF-8 boundaries no longer corrupt text or apply to the wrong lines. (PED-01, PED-02, PED-03, PED-05)
- **Large files:** overlapping selections, Select Next and Select All, keyboard rectangle extension, bookmarks and typing in large-file mode work without errors, and typing merges into one undo step. (PED-04, PED-15, PED-16, PED-18)
- **Large files:** line counting uses one persistent index per document that survives edits, instead of rescanning from the start, and no longer starts a thread per request. (PED-06, PED-07, PED-08, PERF-04)
- **Large files:** carets at window edges, inside folds, after replacements and in cloned views stay on the right text, arrow keys move past the loaded window, Ctrl+End shows the end of the file, and CRLF line endings are never split. (PED-09, PED-10, PED-11, PED-12, PED-13, PED-14, PED-19, PED-20, PED-21, PED-22)
- **Large files:** a loading tab keeps its position, pin and color, the same file can no longer be opened twice, and converting line endings in a selection with hidden lines converts the right range. (PED-23, PED-24, PED-25)
- **Search:** regular expressions handle CRLF line endings: `.` no longer matches the CR, `$` matches before CRLF, and Replace All no longer rewrites CRLF files to LF. (SRC-01)
- **Search:** regular-expression Find All, Count and Replace All no longer stop at the time limit on multi-megabyte files; each match attempt has its own time allowance, the nesting limit is far higher, and a search that does stop names the limit. More patterns, such as `[^,]+` and named groups, are searched window by window. (SRC-03, SRC-06, SRC-12)
- **Search:** Whole Word finds the longer alternative (`x|xy` finds `xy`), the large-file replace preview shows the matched text, and replacement text is decoded exactly once. (SRC-15, SRC-16, SRC-21)
- **Replace in Files:** one skipped file no longer stops the whole folder, a temporary rollback failure can be retried instead of being marked as a conflict, files without a backup are reported as skipped, restored files are checked against their original hash, closed documents with unsaved changes no longer block their file, and exiting during a job asks whether to wait. (SRC-07, SRC-08, SRC-10, SRC-18, WSP-03, APP-10)
- **Compare:** files above 2,048 lines or 1 MiB are compared exactly up to 200,000 lines and 64 MiB, byte-identical documents always show "No differences", and a region that exceeds a limit is shown as one block between matching lines instead of marking the whole file. (SRC-04)
- **Compare:** comparing large (paged) files aligns them on matching lines, so one inserted line no longer marks the rest of the file as changed. Large insertions and removals are reported where they are, and with **Ignore blank lines** a run of blank lines is no longer reported as a change. When the files have too many distinct lines to index, the status reads "Coarse comparison (memory limit)". (SRC-05)
- **Syntax:** syntax colors no longer flash to plain text after an edit; the previous colors stay until the new ones arrive. An edit, or a scroll back up, re-highlights from just before the visible text instead of from the start of the file, with either lexer. Dense files such as pretty-printed JSON keep their highlighting, and a lexer mapping error falls back instead of removing colors. (SRC-13, SRC-14, SRC-20)
- **User-defined languages:** Notepad++ UDL import maps comments, delimiters, folding markers and numbers, reports what it cannot express, and renames a language whose name collides with another. (SRC-19)
- **Macros:** a recording that cannot capture an action is stopped and discarded instead of silently differing from what you did, imported macros are checked before they run, one unreadable macro no longer makes the others unavailable, and an external command whose child process keeps its output open no longer stays "Running". (WSP-07, WSP-08, WSP-09, WSP-15)
- **Workspace:** closed and loading tabs no longer keep their memory or show as broken, **Restore Last Closed Tab** keeps the caret, pin and read-only state, renamed files are rebound instead of reopened, Workspace Delete moves files to the Recycle Bin, and the document map no longer starts a thread per edit. (WSP-01, WSP-02, WSP-04, WSP-05, WSP-12, WSP-13, WSP-16, WSP-17)
- **Run:** commands without a folder of their own start in the workspace, the document's folder or your user folder, never in `System32`. (APP-18)
- **Keyboard:** Add Caret Above and Below (Ctrl+Alt+Up and Down) and Toggle Block Comment (Ctrl+Shift+/) work, including on layouts with AltGr. (WSP-06)
- **Menus and dialogs:** owner-drawn menus are measured again after a DPI change, native menus no longer rebuild every frame, and input latency is capped at one frame. (UI-13, UI-17, UI-19)
- **Accessibility:** screen readers can read long lines and the last line, text ranges survive edits and input method composition, banner actions and Settings controls are exposed with their roles, the editor keeps its text while Find is open, every tab is in the tab list, lists report position and size, and large or recovered documents no longer answer "pending". (A11Y-02, A11Y-03, A11Y-04, A11Y-05, A11Y-06, A11Y-07, A11Y-08, A11Y-09, A11Y-11)

### Security

- **Binaries:** Windows executables are built with Control Flow Guard, and preview packaging rejects executables that lack Control Flow Guard, do not record the expected build commit, or import the Visual C++ runtime DLLs. CET shadow-stack compatibility is not declared, because the regular-expression and extension-host JIT compilers do not support it. (SEC-15)
- **Binaries:** the editor, update helper and extension host load DLLs only from `System32`, never from the user-writable installation folder, and packaging checks this. (SEC-16)
- **External commands:** values from documents are quoted for the program that receives them (`cmd.exe`, batch files, PowerShell) and refused when they cannot be passed as plain data; script hosts and shell launchers receive no values at all; shell mode always runs the system `cmd.exe`; and a placeholder can no longer name the program or set PowerShell startup options. (SEC-10)
- **Extensions:** the extension host, which is disabled in default builds, now fails closed when its sandbox cannot be created, runs at Low integrity on a private desktop with all UI limits, and receives an explicit environment; extension command titles can no longer impersonate built-in commands in the Command Palette. (SEC-05, SEC-06, SEC-21, WSP-10)
- **Updates:** for configured releases (updates are disabled in previews), trust state is kept per user and can be refreshed by a signed update, Authenticode is pinned by signer instead of by leaf certificate, revocation is checked online when you check for or apply an update, builds made for testing are refused, a build that fails to start three times is rolled back automatically, and **Roll Back Last Update** restores the previous build. (SEC-01, SEC-02, SEC-03, SEC-04, SEC-07, SEC-08, SEC-09, SEC-17, SEC-18)
- **Releases:** tagged previews carry GitHub build-provenance attestations for every asset and `SHA-256SUMS`; build paths are normalized and toolchain versions recorded; third-party notices and the SBOM include the native Lexilla, PCRE2 and SLJIT code. (SEC-11, SEC-13, SEC-14, SEC-20)
- **Dependencies:** wasmtime is updated to 48.0.3 for RUSTSEC-2026-0314, RUSTSEC-2026-0315 and RUSTSEC-2026-0316 (extension host only), and yanked crates fail the dependency check. (SEC-20)
